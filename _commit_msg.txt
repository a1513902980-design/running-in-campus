geo_guard: 加参数启动自检，堵住"占位符未替换导致静默失效"

问题：
- 占位符写成 parseFloat('<...>') 是为了让文件天然合法、能过 node --check，
  但忘记替换会得到 NaN，而 NaN 让所有比较恒为 false
  => dist() 返回 NaN、d > RADIUS_M 永远不成立
  => 消毒器"挂上了但一个坐标都不拦"，即本领域最贵的故障：静默失效

修法：
- 新增 assertConfigured() 启动自检：参数未配置时打印醒目错误，
  并**拒绝接管任何坐标入口**（而不是安静地放过一切）
- 挂钩前检查 CONFIG_OK，未通过就直接 return
- README 补上对应警告与成因说明

背景：原始项目里这个坑真实发生过——钩子日志显示"已接管"，
但拦截计数永远是 0，排查了很久。所以把它固化成代码级防护。
